# Release notes

The upcoming 4.0.0 release adds a desktop interface to Aestimo's existing
Python and command-line workflows. The notes below describe the current source;
4.0.0 has not yet been published on PyPI.

For the published package, use `python -m pip install aestimo`. To try the
upcoming GUI, follow the {ref}`source installation <install-source>`.
Published downloads are listed on [PyPI](https://pypi.org/project/aestimo/)
and [GitHub releases](https://github.com/aestimosolver/aestimo/releases).
