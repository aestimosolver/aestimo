## Historical notebooks by Robert J. Steed

The four original notebooks are preserved in `tutorials/`. Their APIs and input
formats predate the current GUI integration; use them for the physical workflow
and adapt code to the current source as needed. They are not executed during
documentation builds.

| Notebook | Topic | Download |
| --- | --- | --- |
| Tutorial 1 | General usage | {download}`Notebook 1 <../tutorials/Aestimo_tutorial1.ipynb>` |
| Tutorial 2 | Hybridising degenerate energy levels | {download}`Notebook 2 <../tutorials/Aestimo_tutorial2.ipynb>` |
| Tutorial 3 | Parabolic potential structures | {download}`Notebook 3 <../tutorials/Aestimo_tutorial3.ipynb>` |
| Tutorial 4 | Optical intersubband transitions | {download}`Notebook 4 <../tutorials/Aestimo_tutorial4.ipynb>` |

The [source notebook directory](https://github.com/aestimosolver/aestimo/tree/master/tutorials)
also provides GitHub previews. Local notebook use requires a Jupyter installation;
it is not a runtime dependency of the simulator.
