Aestimo 1D documentation
==============================

Aestimo simulates one-dimensional semiconductor heterostructures using
Schrödinger–Poisson and drift–diffusion methods. It provides a command-line
interface, a Python interface and a desktop GUI with device presets.

Start with :doc:`installation` and :doc:`first-calculation`. Use :doc:`gui`
for the desktop workflow or :doc:`quickstart` for command-line calculations.
This guide follows the 4.0.0 preparation source; see the installation page for
the distinction between source installation and published releases.
